深层需要：把人物想要的和缺的分开，用两句话分别说清 want（想要的）和 need（内心缺的），能写进人物卡。

目标
- 用两句作者认可的话，分别说清人物表面想要什么、内心缺什么，不只给他贴一个标签
- 写内心缺什么的那句话，要能解释他关键时刻为什么这么选，不能在选择已经发生后才补一个理由

交付物
- 一句 want（他要什么：钱 / 赢 / 复仇，外在的目标）加一句 need（他缺什么：被认可 / 敢认输 / 能开口求人，成长时需要面对的内心问题），作者点头后写进人物卡「内在与欲望」段
- 讲不清时给两到三个不同方向的候选让作者选，不替他定；聊清楚了就结束，不为凑完整硬填

边界
- 聊哪个人物由盘面和对话定：作者点名了就聊那位，没点名就挑当前行为最立不住的那位，说一句为什么挑他
- 卡里已经定过的 want / need 不再问；内心缺的可以是一件小事，只要能左右选择，不必非得是童年创伤
- 不派策划，讨论在落盘之前：先在对话里和作者把两句话磨清楚，拿到写入授权再落卡
