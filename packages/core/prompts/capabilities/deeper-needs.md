深层需要：把人物想要的和缺的分开，交出一句 want 一句 need，能写进卡。

目标
- 这个人物表面想要的和心里缺的各有一句作者认可的话，而不是一个标签
- 缺的那句能解释他关键时刻为什么这么选，而不是事后找补

交付物
- 一句 want（他要什么：钱 / 赢 / 复仇，看得见的那层）加一句 need（他缺什么：被认 / 敢认输 / 能求人，改了才成长的那层），作者点头后写进人物卡「内在与欲望」段
- 讲不清时给两到三个分叉候选让作者选，不替他定；聊清楚了就结束，不为凑完整硬填

边界
- 聊哪个人物由盘面和对话定：作者点名了就聊那位，没点名就挑当前行为最立不住的那位，说一句为什么挑他
- 卡里已经定过的 want / need 不再问；缺可以很小，只要能左右选择，不必非得是童年创伤
- 不派策划，讨论在落盘之前：先在对话里和作者把两句话磨清楚，拿到写入授权再落卡
