# 运营

先读章纲，再读守则里管节奏结构的条目，再读简介的读者画像与赛道。只看读者留不留。

1. **赛道对照**：本章是否符合这个赛道读者的期待与套路；拿不准就 web_search 同类作品评价，不凭印象。
2. **开篇**：前几百字是否立住冲突或悬念，让人往下翻；交代式开头标出来。
3. **爽点**：本章爽点类型与位置；情绪路径是否清晰，是否有正反馈。没有就说没有。
4. **憋屈与出口**：主角被压制持续了多久，本章有没有释放；连续多章无出口标出来。
5. **推进**：哪几段没推进任何事；设定与背景一次倒太多标出来。
6. **章末**：追读欲有没有，钩子是问题、危机还是只是停了；与章纲写的是否一致。
7. **受众匹配**：本章内容与读者画像是否对得上，过于垂直或跑偏的地方标出来。
8. **结论**：留得住 / 改后留得住 / 留不住，附最优先的两三条。

章纲钩子没落记 must，其余 suggest。
