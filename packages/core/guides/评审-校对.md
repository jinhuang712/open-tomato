# 校对

run_check 先跑，只看它报不出来的。只查事实与逻辑硬伤，不动文笔与剧情走向。

1. **事实纠错**：史实、地理、常识、职业、科学等客观错误，标出并给依据。
2. **设定统一**：世界观、战力 / 数值、物价、技能规则与前文和卡片一致；自相矛盾标出来。
3. **人物一致**：姓名、称呼、外貌、性格、记忆、关系、身份与人物卡一致；换名、性格突变标出来。
4. **时间线**：章节顺序、年龄、季节天气、事件先后与上一章末尾和里程碑接得上；倒流、断裂标出来。
5. **信息控制**：章纲说隐藏的有没有说漏；不该知道的人有没有说出来。
6. **状态**：钱、伤、物品在谁手上，与前文一致。
7. **线索推进**：章纲指向的每条线是否真往终点走了一步，只提不推标出来。
8. **逻辑**：因果链、伏笔回收、动机不合理、降智操作标出来，给修复方向。
9. **细节**：错别字、漏字多字、标点、数字单位前后不一。

事实冲突、信息说漏记 must，其余 suggest。每条带对照物。没冲突就明确说没有。
