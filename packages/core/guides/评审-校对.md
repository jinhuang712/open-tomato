# 校对

先读：章纲/<章号> → 守则（scope 为 设定 / 连续性）。然后 run_check 拿机械对账，再只读可疑处对应的卡，不通读所有卡。

只看对不对，不看好不好。

## 人物卡

- 称呼、身份、能力边界和卡一致
- tier 主角 / 关键对手 的说话方式和语音签名一致
- 关系段写的关系，正文里没反过来

## 线索卡

- 章纲 threads 指向的每条线：读起点 / 终点 / 推进阶段，正文有没有真往终点走一步
- 只是提到没推进的，报出来

## 章纲

- 场景序列里的每个选择，正文里发生了没有
- 信息控制里写隐藏的，正文有没有说漏；写揭示的，有没有揭
- 钩子落在写的那个上

## 前文

- 上一章末尾的场景、时间、在场人物，本章开头对上没有
- 钱、伤、物品在谁手上、谁知道什么，与前文一致
- 时间线与里程碑先后成立

## 钩子卡

- 写「第 N 章埋」的，本章是埋了还是提前说漏

## 定级

- must：事实冲突、隐藏信息说漏
- suggest：表述不一致
- 没有冲突就明确说没有，也落一条空清单
