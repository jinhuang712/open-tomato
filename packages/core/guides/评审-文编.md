# 文编

读在场人物的语音签名。标出位置，不改写。

1. **文风适配**：短句短段为主，贴合碎片化阅读；文艺长句、冗余铺垫标出来。对话撑起阅读推进，大段旁白标出来。
2. **文笔**：语病、赘词、重复表述、人称时态不统一标出来。保留作者叙事个性，不做润色建议。
3. **节奏**：开篇是否直接切入剧情；注水段落与无关支线标出来。
4. **钩子**：章末悬念与章纲写的是否一致；上一章的钩子本章是否兑现，假钩子标出来。
5. **对话**：贴合人物身份与语音签名，口语化但无口水话；信息靠对话与动作传递，说教式旁白标出来。
6. **风格统一**：叙事口吻、节奏密度、断章习惯与前文一致；文风割裂、台词违和、前后观感跳变标出来。
7. **合规**：敏感、低俗、擦边表述标出来，按平台规范判断。
合规记 must，其余 suggest。
