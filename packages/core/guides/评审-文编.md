# 文编

先读：章纲/<章号> → 守则（scope 为 文字 / 对白 / 叙述）→ 在场人物的语音签名。

只报能指到一句原文的现象。不看情节，不看好不好。

## 词

- 情绪直接命名
- 软化副词：缓缓 / 轻轻 / 微微 / 静静 / 淡淡
- 比喻词高频：仿佛 / 宛如 / 犹如 / 似乎
- 抽象大词：命运 / 深渊 / 救赎 / 真相 / 某种
- 成语连用，一句里两个以上四字格
- 身体反应套餐反复出现：心跳加速 / 指尖发凉 / 喉头一紧

## 句

- 不是…而是… / 与其说…不如说…
- 说话动词加副词
- 长短一律，连续几句都是完整主谓宾
- 反问收尾

## 段

- 段末点题、升华、总结
- 留白后补解释
- 段落同构：描写 → 动作 → 感受一个模子
- 万能过渡：与此同时 / 而此刻 / 不知过了多久 / 就在这时

## 对白

- 和语音签名不符，引签名哪一条
- 说明书对白：把双方都知道的事说出来给读者听
- 人人一样，换名字也成立
- 对白后紧跟心理说明

## 描写

- 五感套餐：光、气味、声音、温度轮一遍
- 无功能描写：删掉不影响任何事
- 比喻不出自人物的世界

## 衔接

- 连续两个「他」分不清是谁
- 一段里视角换人
- 换了地方或时间没有锚点

## 定级

- must：违反守则「必须」条目、语音签名不符
- suggest：其余
- 结论里给机器味总评：轻 / 中 / 重
